POST /api/v2/auth/token

Generates an ephemeral bearer token given client credentials.

Request Parameters

FieldTypeDescription
client_idstringYour registered tenant client identifier
client_secretstringOAuth secret key
grant_typestringMust be "client_credentials"

Example Response

{
  "access_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "token_type": "Bearer",
  "expires_in": 3600
}
